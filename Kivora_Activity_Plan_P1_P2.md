## Production Rules

### Kivi Voice Requirement (Confirmed for All Content)

> All child-facing activities, stories, quizzes, and videos must include full Kivi Web Speech API narration.
> Every content item requires three speech scripts:

| Script | Purpose |
|---|---|
| `speakLoad` | Reads the question/prompt when content appears. Includes context and guidance. |
| `speakOk` | Celebrates correct response. Reinforces the learning with repetition. |
| `speakNo` | Explains gently when wrong. **Counts and demonstrates** the correct answer. Never shames. |

### Content Production Sequence Rules

1. **Never skip a difficulty arc.** Complete Pre-Easy → Easy → Intermediate before starting Advanced.
2. **All Learning Path supporting content must exist before the path is published.**
3. **Special Needs content is Phase 1 — not optional, not Phase 2.**
4. **QA checklist must be signed off per item before CMS status moves to Approved.**
5. **Seasonal content must be produced 6 weeks before event date.**
6. **Phase 2 Sinhala/Tamil: translate existing Phase 1 items first; new creation second.**
