KIVORA MASTER PLATFORM SPECIFICATION (v2.0)

────────────────────────────────────────────────────────────
VISION
────────────────────────────────────────────────────────────
Kivora is a child-safe, gamified, adaptive learning ecosystem
for children aged 2–11 (Toddler to Grade 5), combining
learning, creativity, exploration, storytelling, games,
videos, coloring, printables, and life skills into a single
adventure-based platform.

────────────────────────────────────────────────────────────
SKILL-TO-GRADE MAPPING
────────────────────────────────────────────────────────────
This table anchors the Adaptive Learning Engine's difficulty
selection and world-unlock logic.

Toddler (Age 2–3)
  Difficulty  : Pre-Easy (Sensory)
  Worlds      : Alphabet Island (letters only),
                Creativity Kingdom (colouring only)
  Gate        : Parent profile setup only — no assessment

Pre-K (Age 3–4)
  Difficulty  : Easy
  Worlds      : Alphabet Island, Creativity Kingdom,
                Music Meadow
  Gate        : Auto-placed on parent account creation

Kindergarten (Age 5–6)
  Difficulty  : Easy → Intermediate
  Worlds      : Alphabet Island, Math Mountain (counting),
                Story Cove, Music Meadow
  Gate        : Optional 5-minute placement quiz

Grade 1 (Age 6–7)
  Difficulty  : Intermediate
  Worlds      : All above + Science Safari (intro),
                Brain Game Galaxy (intro)
  Gate        : Placement quiz recommended

Grade 2 (Age 7–8)
  Difficulty  : Intermediate
  Worlds      : All above + Life Skills Village,
                Coding City (intro blocks)
  Gate        : Placement quiz recommended

Grade 3 (Age 8–9)
  Difficulty  : Intermediate → Advanced
  Worlds      : All worlds; Coding City (block coding)
  Gate        : Placement quiz required for Advanced tier

Grade 4 (Age 9–10)
  Difficulty  : Advanced
  Worlds      : All worlds; Coding City (logic puzzles)
  Gate        : Skill mastery badges gate Advanced content

Grade 5 (Age 10–11)
  Difficulty  : Advanced → Master
  Worlds      : All worlds; Coding City (text-based intro)
  Gate        : Mastery badge in 3+ subjects for Master tier

PROGRESSION RULES
- Advance trigger    : 80%+ accuracy over 5 consecutive
                       activities at current tier
- Hold trigger       : 60–79% accuracy — reinforce with
                       varied content at same tier
- Step-down trigger  : Below 60% across 3 consecutive
- Mastery badge      : 90%+ on end-of-tier assessment
- Adult override     : Parent or teacher can manually
                       adjust tier at any time
- World unlock       : Grade-based by default; parent or
                       teacher can unlock early

REWARDS ECONOMY
────────────────────────────────────────────────────────────

XP EARN RATES
Activity (Easy)              10 XP    Daily cap: 50 XP
Activity (Intermediate)      20 XP    Daily cap: 100 XP
Activity (Advanced)          35 XP    Daily cap: 175 XP
Activity (Master)            50 XP    Daily cap: 250 XP
Perfect score bonus         +10 XP    No daily cap
Daily Mission complete       25 XP    Daily cap: 75 XP
Read a story (finish)        15 XP    Daily cap: 45 XP
Watch educational video      10 XP    Daily cap: 30 XP
Portfolio submission         30 XP    Daily cap: 30 XP
7-day login streak bonus    100 XP    Once per streak
Mastery badge earned        200 XP    One-time per badge

Daily caps reset at midnight local time.

XP LEVELS
Level 1   |     0 XP  |  Explorer
Level 2   |   200 XP  |  Adventurer       → Avatar accessories
Level 3   |   500 XP  |  Discoverer       → Background theme #1
Level 4   | 1,000 XP  |  Trailblazer      → Animated avatar effect
Level 5   | 2,000 XP  |  Champion         → Special badge frame
Level 6   | 3,500 XP  |  Star Learner     → Dashboard theme
Level 7   | 5,500 XP  |  Knowledge Seeker → Rare avatar item
Level 8   | 8,000 XP  |  Master Mind      → Certificate upgrade
Level 9   |11,500 XP  |  Genius           → Parent Hall of Fame
Level 10  |16,000 XP  |  Kivora Legend    → Physical reward*

*Physical reward applies to paid subscriptions only.

BADGE TYPES
Subject Mastery  - Complete mastery assessment per world tier
Streak           - Maintain login or activity streaks
                   (7-day, 30-day, 100-day variants)
Speed            - Complete activities within time challenges
Creativity       - Submit and earn approval on portfolio items
Helping          - Peer assistance in classroom mode
Seasonal         - Participate in seasonal events/challenges
                   (recurs annually — never permanently missed)
World Completion - Reach Master tier in a Learning World

REWARD CONTROLS
- Parents can set a daily XP cap (override platform defaults)
- Parents can disable cosmetic unlocks while keeping XP/badges
- Parents can require approval before rewards are redeemed
- Teachers can create custom classroom badges, award manually
- School admins can toggle the rewards system institution-wide
- No real-money purchases in the child portal
  All rewards are earned, not bought

SAFETY GUARDRAIL
The rewards system must not create FOMO-driven pressure.
Design constraints (non-negotiable):
- No countdown timers on rewards
- No permanently missable rewards (seasonal items recur)
- No scarcity mechanics
- Progress shown as forward-looking bars, not loss framing

────────────────────────────────────────────────────────────
SPECIAL EDUCATION SUPPORT
────────────────────────────────────────────────────────────
Conditions supported:
- Autism
- ADHD
- Dyslexia
- Speech Delays
- Fine Motor Challenges

Platform accommodations (per condition):
- Autism      : Reduced visual noise, predictable navigation,
                no sudden audio/animation surprises,
                social story content format available
- ADHD        : Shorter activity segments (5–8 min),
                frequent reward check-ins, focus mode
                (minimal UI chrome), movement break prompts
- Dyslexia    : Dyslexia-friendly font option, audio read-
                aloud on all text, extended time on timed
                activities, high contrast mode
- Speech      : Visual/gesture-based response options,
                no mandatory voice input
- Fine Motor  : Large tap targets, drag-and-drop
                alternatives, adjustable interaction zones

Accessed via: /parent/settings/accessibility
Parent sets condition flags; child UI adapts automatically.
No diagnosis data is stored — settings are preference-based.
